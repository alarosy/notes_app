# دفتر الملاحظات الشخصي

موقع بسيط لتسجيل الملاحظات اليومية وتصنيفها والبحث فيها. مشروع لمقرر برمجة الويب، مبني بـ PHP الخام (دوال `mysqli` الإجرائية) وMySQL بجدول واحد، دون أي إطار عمل أو مكتبات خارجية، ويعمل دون اتصال بالإنترنت.

إعداد الطالب: [اسم الطالب]

## ماذا يفعل البرنامج؟

- **إضافة ملاحظة:** عنوان، وتصنيف من قائمة (شخصي، دراسة، عمل، أفكار، أخرى)، ونص.
- **عرض الملاحظات:** بطاقات مرتبة من الأحدث. في كل بطاقة العنوان، وشارة ملوّنة للتصنيف، ومقتطف من النص، والتاريخ.
- **تعديل ملاحظة** من صفحة مستقلة.
- **حذف ملاحظة** مع رسالة تأكيد قبل الحذف.
- **بحث في العناوين** يمكن دمجه مع **فلتر التصنيف**، مع زر "مسح البحث".
- **عداد** لعدد الملاحظات المعروضة، ورسائل نجاح بعد كل عملية، ورسالة واضحة عند عدم وجود نتائج.
- واجهة عربية من اليمين لليسار، تعمل على الحاسوب والجوال.

## الأمان المطبّق

- كل الاستعلامات التي فيها مدخلات تستخدم Prepared Statements، للحماية من حقن SQL.
- كل ما يُعرض في الصفحة يمر عبر `htmlspecialchars`، للحماية من XSS.
- الحذف والتعديل عبر `POST` فقط.
- التحقق من كل المدخلات على الخادم، مع إبقاء ما كتبه المستخدم عند الخطأ.
- نمط Post/Redirect/Get حتى لا يكرر تحديث الصفحة العملية.

## المتطلبات

- PHP 8.0 أو أحدث، مع الإضافتين `mysqli` و`mbstring`
- MySQL 8 أو MariaDB 10.4 أو أحدث
- خادم Apache، أو حزمة جاهزة مثل XAMPP

## التشغيل على Windows باستخدام XAMPP

1. ثبّت [XAMPP](https://www.apachefriends.org)، وشغّل Apache وMySQL من لوحة التحكم.
2. حمّل المشروع: زر **Code** ثم **Download ZIP** أعلى هذه الصفحة. فك الضغط، وسمِّ المجلد `notes_app`، وضعه داخل `C:\xampp\htdocs\`.
3. افتح `http://localhost/phpmyadmin`:
   - أنشئ قاعدة بيانات باسم `notes_db` بترميز `utf8mb4_unicode_ci`.
   - اخترها، ثم من تبويب **Import** اختر الملف `database.sql` واضغط **Go**.
4. افتح `config.php` وعدّل بيانات الاتصال في أوله. في XAMPP الافتراضي:

   ```php
   $db_user = 'root';
   $db_pass = '';
   ```

5. افتح المتصفح على: `http://localhost/notes_app`

## التشغيل على Linux (Ubuntu)

```bash
sudo apt install apache2 mysql-server php libapache2-mod-php php-mysql php-mbstring git
cd /var/www/html
sudo git clone <رابط هذا المستودع> notes_app

sudo mysql -e "CREATE DATABASE notes_db CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
CREATE USER IF NOT EXISTS 'student'@'localhost' IDENTIFIED BY 'Student@2026';
GRANT ALL PRIVILEGES ON notes_db.* TO 'student'@'localhost';"
mysql -u student -p notes_db < notes_app/database.sql
```

ثم افتح `http://localhost/notes_app`.

بيانات الاتصال الافتراضية في `config.php` هي `student` / `Student@2026`، وهي للتطوير المحلي فقط. غيّرها إن نشرت المشروع على خادم حقيقي.

## طريقة الاستخدام

| أريد أن... | الطريقة |
|---|---|
| أضيف ملاحظة | املأ النموذج أعلى الصفحة الرئيسية واضغط "حفظ الملاحظة" |
| أبحث | اكتب جزءًا من العنوان في شريط البحث، واختر تصنيفًا إن أردت، ثم اضغط "بحث" |
| أعدّل | زر "تعديل" في البطاقة |
| أحذف | زر "حذف" في البطاقة، ثم وافق على رسالة التأكيد |

## هيكل الملفات

| الملف | الدور |
|---|---|
| `config.php` | الاتصال بقاعدة البيانات، وقائمة التصنيفات، ودوال مساعدة (`e()` والتحقق) |
| `index.php` | الصفحة الرئيسية: الإضافة والعرض والبحث والفلترة |
| `edit.php` | صفحة تعديل ملاحظة |
| `delete.php` | تنفيذ الحذف (يقبل `POST` فقط) |
| `style.css` | التنسيق |
| `database.sql` | إنشاء جدول `notes` مع 6 ملاحظات تجريبية |
| `دليل_المناقشة.md` | شرح تفصيلي للكود، وأسئلة المناقشة، وتمارين |

## قاعدة البيانات

جدول واحد `notes`: `id`، و`title`، و`content`، و`category`، و`created_at`، و`updated_at`. يحدّث MySQL عمود `updated_at` تلقائيًا عند أي تعديل.

## مشاكل شائعة

- **"تعذّر الاتصال بقاعدة البيانات":** تأكد أن MySQL يعمل، وأن البيانات في `config.php` صحيحة، وأن القاعدة `notes_db` موجودة.
- **تظهر علامات استفهام بدل الحروف العربية:** تأكد أن القاعدة أُنشئت بترميز `utf8mb4`، ثم أعد استيراد `database.sql`.
- **الصفحة فارغة أو 404:** تأكد أن اسم المجلد `notes_app` بالضبط، وأنه داخل `htdocs` (XAMPP) أو `/var/www/html` (Linux).

لإعادة البيانات التجريبية في أي وقت، أعد استيراد `database.sql`، فهو يحذف الجدول ويعيد إنشاءه.
